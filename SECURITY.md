# Security Policy

## Supported Versions

Security fixes are currently applied to the latest release line.

| Version | Supported |
| --- | --- |
| Latest `0.x` | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

Please do **not** open public issues for suspected vulnerabilities.

Instead, report privately by opening a GitHub Security Advisory draft:

- https://github.com/maestromaximo/codex-local-sdk-python/security/advisories/new

Include:

1. A clear description of the issue and impact.
2. Reproduction steps or proof of concept.
3. Any suggested mitigation.
4. Your contact information for follow-up.

You can expect an initial response within 5 business days.
