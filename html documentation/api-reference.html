Session Stores

Map a logical session name (for example, "repo-plan") to a Codex thread/session ID.

SessionStore (Abstract Interface)

  • get(name) -> str | None
  • set(name, session_id) -> None
  • delete(name) -> None
  • all() -> dict[str, str]

InMemorySessionStore

Default store for short-lived process memory.

JsonFileSessionStore

Persistent local store backed by a JSON file, using atomic write/replace semantics.

Named Session Example

from codex_local_sdk import CodexLocalClient, JsonFileSessionStore

client = CodexLocalClient(session_store=JsonFileSessionStore(".codex_sessions.json"))
session, _ = client.start_thread("Analyze repo", session_name="repo-plan")

next_result = client.resume(
    prompt="Continue with implementation steps",
    session_name="repo-plan",
    last=False,
    json_output=True,
)

CodexLiveRun

Runtime controller for active sync live operations (run_live and resume_live).

  • pid, events, is_complete, return_code
  • iter_events(), wait(timeout=None), result()
  • terminate(), kill()

AsyncCodexLiveRun

Async live run controller returned by run_live_async and resume_live_async.

Properties

  • pid, events, is_complete, return_code

Methods

  • async iter_events()
  • async wait(timeout=None)
  • async result()
  • terminate(), kill()

Example

live = await client.run_live_async(CodexExecRequest(prompt="Stream events", json_output=True))
async for event in live.iter_events():
    print(event.type)
result = await live.wait()

CodexThreadSession

High-level object for continuing a previously started execution thread/session.

Fields and Helpers

  • session_id: extracted thread identifier.
  • session_name: optional logical name stored in SessionStore.
  • last_result: most recent continuation result.
  • is_last_turn_complete: completion helper.

Methods

  • continue_prompt(...)
  • continue_prompt_async(...)
  • continue_live(...)
  • continue_live_async(...)
