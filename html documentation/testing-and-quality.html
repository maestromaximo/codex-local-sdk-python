Testing and Quality Guide

The suite uses unittest with mocks for subprocess calls and includes dedicated coverage for async, retries/backoff, and session store persistence.

Run the Test Suite

python3 -m unittest discover -s tests -p "test_*.py"

Key suite files:

  • tests/test_codex_local_sdk.py
  • tests/test_client_sync_extended.py
  • tests/test_client_live_extended.py
  • tests/test_models_and_sessions_extended.py
  • tests/test_async_retry_and_session_store.py

Add New Tests

Pattern: Retry Policy

@patch("codex_local_sdk.client.shutil.which", return_value="/usr/bin/codex")
@patch("codex_local_sdk.client.time.sleep")
@patch("codex_local_sdk.client.subprocess.run")
def test_retry_until_success(mock_run, mock_sleep, _mock_which):
    mock_run.side_effect = [
        SimpleNamespace(returncode=7, stdout="", stderr="tmp"),
        SimpleNamespace(returncode=0, stdout="ok", stderr=""),
    ]
    client = CodexLocalClient(retry_policy=RetryPolicy(max_attempts=3))
    result = client.run(CodexExecRequest(prompt="x"))

    assert result.ok
    assert mock_run.call_count == 2
    mock_sleep.assert_called_once()

Pattern: Async Live

class TestAsyncApi(unittest.IsolatedAsyncioTestCase):
    async def test_run_live_async(self):
        # patch asyncio.create_subprocess_exec with fake process
        live = await client.run_live_async(CodexExecRequest(prompt="x", json_output=True))
        events = [event async for event in live.iter_events()]
        result = await live.wait()

        assert len(events) > 0
        assert result.is_turn_terminal

Pattern: Session Store Persistence

def test_json_file_store_roundtrip(tmp_path):
    store = JsonFileSessionStore(str(tmp_path / "sessions.json"))
    store.set("plan", "thread-1")
    assert store.get("plan") == "thread-1"

    store.delete("plan")
    assert store.get("plan") is None

CI Guidance

  • Keep tests hermetic: mock CLI invocation and never require real Codex auth in unit tests.
  • Run full unit suite on every pull request.
  • Add integration smoke tests only in controlled environments with secure credentials.
  • Include both raise_on_error=True and False paths for new command code.
  • For async changes, add at least one IsolatedAsyncioTestCase scenario.

Quality Checklist

  • New public methods documented in api-reference.html.
  • At least one runnable example added/updated in examples/.
  • Tests include success, failure, and edge-path assertions.
  • No secrets in examples, docs, fixtures, or committed session files.
See tests/test_async_retry_and_session_store.py for async/retry/store baseline coverage.
